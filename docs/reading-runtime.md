# 리딩을 무엇으로 만들 것인가 — 배포 스위치

문장을 만드는 길과 그 비용을 정하는 값은 **전부 환경변수**입니다. 코드를 고치지 않고
배포 설정만 바꾸면 되고, 되돌리는 것도 같은 방법입니다.

지금 상태는 `npm run ai:doctor` 로 봅니다. 실제로 뚫려 있는지까지 보려면
`npm run ai:doctor -- --call` (열 토큰).

---

## 한 줄 요약

| 어디서 | 무엇으로 | 왜 |
| --- | --- | --- |
| 내 컴퓨터 | `AI_PROVIDER=claude-code` | 구독으로 돈다. 종량과금 0 |
| Vercel | `AI_PROVIDER=openai` | **claude-code 는 여기서 안 된다** |

## claude-code 가 Vercel 에서 안 되는 이유

이 길은 HTTP 를 부르지 않습니다. 로그인된 Claude Code CLI 를 **프로세스로 띄워서**
stdout 을 읽습니다. 그래서 두 가지가 있어야 합니다.

1. `claude` 실행 파일 — 전역 npm 설치
2. 로그인된 세션 — 사람이 브라우저로 한 번 해야 만들어짐

서버리스에는 둘 다 없습니다. 이미지에 전역 설치가 없고, 로그인은 무인 환경에서
만들 수 없습니다.

`ai.ts` 가 이걸 **미리 막습니다.** `VERCEL`·`AWS_LAMBDA_FUNCTION_NAME`·`K_SERVICE`·
`NETLIFY` 중 하나라도 있으면 claude-code 로 가지 않고 곧바로 오류를 냅니다.
안 막으면 배포는 되고 사용자가 생성 버튼을 누른 뒤에야 실패합니다 — 가장 늦게
알게 되는 자리입니다.

**조용히 다른 곳으로 새게 두지 않았습니다.** 구독으로 돌리라고 못 박아 둔 서버가
몰래 종량과금으로 넘어가면, 그 사실을 청구서에서 알게 됩니다.

구독으로 실제 서비스를 돌리려면 CLI 를 둘 수 있는 서버(VPS·전용 머신)가 필요합니다.

## 스위치

### `AI_PROVIDER`
| 값 | 뜻 |
| --- | --- |
| (없음) | 키 우선순위대로 — anthropic → gemini → openai |
| `openai` | 종량과금. **Vercel 은 이것만 됩니다** |
| `anthropic` | 종량과금 |
| `gemini` | 무료 티어는 하루 20·분당 5 요청이라 상품에 못 씁니다 |
| `claude-code` | 구독. CLI 가 있는 서버에서만 |

못 박아 두면 그 키가 없을 때 **다른 곳으로 새지 않고 그냥 실패합니다.** 그게 맞습니다 —
"키가 있는 곳으로 알아서 간다"는 편의는 "돈이 있는 곳으로 알아서 간다"는 편의이기도
합니다.

### `OPENAI_MODEL`
| 값 | 한 편 원가(속궁합 12절) | 990원 대비 |
| --- | --- | --- |
| `gpt-5.6` (지금 `.env`) | $0.176 | 25.8% |
| `gpt-4o-mini` (코드 기본값) | $0.019 | 2.8% |

4o-mini 품질은 **아직 안 쟀습니다.** 한 편($0.019)이면 재집니다.

### `READING_PREVIEW_SECTIONS` (1~4, 기본 2)
결제 전에 만드는 절 수. **원가의 아홉 할이 여기서 나갑니다** — 결제하지 않는
사람에게도 이만큼은 만들어 주기 때문입니다.

광고에서 들어온 사람은 표지에서 끊기므로 첫 절의 두 문장만 봅니다. 그 길만 보면
`1` 로도 충분합니다.

> ⚠️ 이 값이 묶음 경계를 정하고, 결제 뒤 이어 만들 때 그 경계로 "어디까지 만들었는지"를
> 셉니다. **만들다 만 리딩이 있는 채로 바꾸면 절이 빕니다.** 경계가 어긋나면 서버
> 로그에 몇 개가 비는지 찍힙니다.

### `READING_DEMO_MODE` (`on`/`off`, 기본 `off`)
`on` 이면 모델을 부르지 않고 미리 만들어 둔 리포트를 씁니다. 명식·지수는 그대로
계산하고, 글이 샘플이라는 사실을 화면에 밝힙니다.

흐름·화면 테스트용입니다. **켜진 채로 배포하면 돈 받고 남의 글을 파는 일이 됩니다.**

지금 채워진 자리: `sokgunghap`. 비어 있는 자리는 평소대로 모델을 부릅니다.
채우려면 `npm run demo:fixture -- --product insun`.

### `CLAUDE_CODE_BIN` / `CLAUDE_CODE_MODEL` / `CLAUDE_CODE_TIMEOUT_MS`
CLI 실행 파일 자리, 모델(`sonnet` 기본), 시간 제한(180초 기본).
Windows 에서 실행 파일을 못 찾으면 `PATH` 의 `claude.cmd` 로 떨어집니다.

## 원가를 재는 법

```
npm run reading:cost                              지금 설정으로
READING_PREVIEW_SECTIONS=1 npm run reading:cost   미리보기를 줄이면
```

모델을 부르지 않습니다. 프롬프트와 목차는 결정론적이라 입력 토큰은 세면 되고,
출력은 이미 만들어 둔 리포트에서 잽니다.
