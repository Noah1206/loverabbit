# 명리 계산 정책

이 문서는 **우리가 무엇을 채택했는가**를 적습니다. "무엇이 옳은가"가 아닙니다.
유파가 갈리는 자리는 하나로 몰래 정하지 않고, 여기에 선택지와 현재 값을 남깁니다.

정책 버전 `myeongri-policy-1.0.0` · 지장간 표 `jipyeong-standard-2026-08`

계산 결과(`SajuFacts.policy`)와 감사 보고서에 이 두 버전이 함께 실립니다.
나중에 "이 리딩은 어느 기준으로 뽑았는가"를 되짚을 수 있어야 하기 때문입니다.

## 1. 시간

| 항목 | 채택 | 구현 |
|---|---|---|
| 표준시 | 한국 표준시(UTC+9, 동경 135도). 1948~1961년 사이의 표준시 변경 구간을 반영 | `korea-time.ts` |
| 서머타임 | 시행 연도에 한해 보정 | `korea-time.ts` |
| 진태양시 | 출생지 경도로 보정. 기본값 서울(126.978도) → 약 −32분 | `korea-time.ts` |
| 일주 경계 | **자정 기준(야자시)**. 자시를 전날로 넘기지 않음 | `korea-time.ts` |
| 절기 | 태양 황경으로 계산(Meeus). 월 경계는 절입, 해 경계는 입춘 | `solar-terms.ts` |
| 시각 미상 | 시주를 세우지 않고 세 기둥으로만 읽음. 그 사실을 `calculationNotes` 에 남겨 리포트의 `confidence_note` 로 내보냄 | `korea-time.ts` |

**미결정** — 야자시/조자시를 나누는 유파를 따를지. 지금은 나누지 않습니다.

## 2. 지지의 음양 ★

지지를 십성의 담지자로 읽을 때 음양을 무엇으로 볼 것인가.

| 모드 | 뜻 |
|---|---|
| `body` | 지지 자체의 음양. 자인진오신술=양, 축묘사미유해=음 |
| `main_hidden_stem` | 지장간 **본기**의 음양. 자평명리에서 널리 쓰는 쪽 |

**현재 운영 기본값: `body`** — 환경변수 `BRANCH_YIN_YANG_MODE` 로 바꿉니다.
값이 없으면 `body`, 알 수 없는 값이면 경고를 남기고 `body` 로 떨어집니다.

네 지지에서 갈립니다. 체와 용이 어긋나는 자리입니다.

| 지지 | 체 | 본기 | 본기 음양 |
|---|---|---|---|
| 자 | 양 | 계 | 음 |
| 사 | 음 | 병 | 양 |
| 오 | 양 | 정 | 음 |
| 해 | 음 | 임 | 양 |

이 차이는 지지에서 나온 십성을 비견↔겁재, 식신↔상관, 정관↔편관, 정재↔편재,
정인↔편인으로 뒤집습니다. **정과 편은 해석이 반대 방향**이므로 리딩 내용이 달라집니다.

영향 규모는 `npm run myeongri:audit:branch-yinyang` 으로 직접 재 보세요.
보고서는 `docs/audit/branch-yin-yang-comparison.md` 에 생성됩니다.

**모드가 개입하는 범위** — 십성을 매길 때뿐입니다. 지지의 오행, 합·충·형·해·파,
삼합·방합은 지지 그 자체로 보므로 모드와 무관합니다. (`policy.ts` 의 `branchIsYang`
하나만 모드를 압니다.)

**미결정** — 운영 기본값을 `main_hidden_stem` 으로 옮길지.

## 3. 지장간

`src/lib/myeongri/hidden-stems.ts` 가 유일한 출처입니다. 12지지 전부에 여기·중기·본기
역할을 붙여 두었습니다.

**판본이 갈리는 자리** — 채택 출처를 확정해야 합니다.

- 해(亥)의 여기를 무(戊)로 두는 표와, 임(壬)·갑(甲) 둘만 두는 표가 있습니다.
  지금은 무를 둡니다.
- 오(午)의 중기를 기(己)로 두는 표와 두지 않는 표가 있습니다. 지금은 둡니다.
- **일수(日數) 배분은 담지 않았습니다.** 여기/중기/본기가 각각 며칠인지는 표마다
  다르고, 지금은 월령 심천을 보지 않으므로 필요가 없습니다. 보게 되면 그때 정합니다.

## 4. 형충회합

| 관계 | 상태 |
|---|---|
| 충 | 여섯 쌍 전부 |
| 육합 | 여섯 쌍 전부 |
| 삼합 | 네 국 전부 |
| 천간합 | 다섯 쌍 전부. 합화(合化)와 기반(羈絆)을 나눠 봄 |
| **형** | **이번에 추가.** 인사신·축술미 삼형, 자묘 상형, 진진·오오·유유·해해 자형 |
| 파·해 | 없음 |

**형의 처리**

- 삼형은 세 글자가 다 있을 때 `complete`, 두 글자면 `partial`
- **`partial` 은 점수·서술에 쓰지 않습니다.** 부분 성립을 실질 성립으로 볼지는 미결정
- 자형은 같은 글자가 **둘 이상**일 때만. 하나로는 성립하지 않습니다
- **본명식만** 봅니다. 대운·세운을 섞은 교차 형은 보지 않습니다 — 타고난 것과
  지나가는 것을 같은 무게로 두면 구분이 사라집니다

**미결정** — 부분 삼형의 반영 여부, 대운·세운까지 합쳐 볼지, 파·해를 넣을지.

## 5. 신살

| 신살 | 규칙 | 기준지 |
|---|---|---|
| 도화 | 삼합 생지의 다음 글자 | 연지·일지 |
| 역마 | 삼합 생지의 충 | 연지·일지 |
| 화개 | 삼합의 고지 | 연지·일지 |
| 홍염 | 일간 기준 | 일간 |
| 양인 | 양간의 제왕. 음간은 보지 않음 | 일간 |
| 원진 | 자미·축오·인유·묘신·진해·사술 | 지지 쌍 |

**화개가 흔한 것은 계산 오류가 아닙니다.** 화개는 삼합의 고지(진술축미)이고,
연지나 일지가 그 자체로 고지면 스스로 화개가 됩니다. 진술축미가 12지 중 넷이라
자기 적중이 잦고, 연지·일지 두 기준을 함께 보니 더 잦아집니다. **명리적으로 정상**이므로
계산에서 빼거나 감점하지 않습니다. 화면에서 얼마나 앞세울지는 노출 정책의 문제입니다
(`docs/myeongri/rule-boundaries.md`).

**미결정** — 홍염은 판본이 갈립니다. 현재 표는 `saju-shinsal.ts` 에 적혀 있습니다.

## 6. 강약

득령(월지)·득지(일지)·득세(같은 편 글자 수)로 점수를 냅니다. 62 이상 신강,
42 이하 신약, 그 사이 중화입니다.

**통근·투간은 증거로만 냅니다.** `SajuFacts.strengthEvidence` 에 각 천간이 어느 지지의
어떤 지장간 역할에 뿌리내렸는지, 어떤 지장간이 천간에 드러났는지가 들어 있습니다.
**점수에는 반영하지 않습니다** — 여기·중기·본기에 몇 점씩 줄지는 유파마다 다르고,
임의로 정하면 그 숫자가 사실처럼 굳기 때문입니다.

가중치가 필요하면 `TONGGEUN_WEIGHT_PROFILE` 로 프로필을 명시합니다.
기본값은 `none`(점수를 내지 않음)입니다.

**미결정** — 가중치 프로필의 값, 그리고 새 강약 모델을 운영 기본값으로 올릴지.

---

## 7. 성별

- **십성 계산은 성별과 무관합니다.** 같은 명식은 성별이 달라도 같은 십성을 냅니다
- 성별이 갈리는 것은 **해석층**뿐입니다: 여자는 관성이 배우자성, 남자는 재성이 배우자성
- **성별은 사용자가 명시한 값만 씁니다.** 추론하지 않습니다
- 미입력(`unspecified`)이면 성별 특정 해석을 적용하지 않습니다

자세한 경계는 `docs/myeongri/rule-boundaries.md` 를 보세요.
