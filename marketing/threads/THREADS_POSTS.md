# Threads 게시물 — 러브레빗 (@loverebbit)

첫 주 운영분 5편. `py -3 post.py --profile loverabbit` 로 게시한다.

**Threads 전용 규칙** (IG CAPTIONS.md 대비 차이)
- 본문 500자 제한. 해시태그 대신 **주제 태그 1개**만 쓴다 (`--topic`).
- 링크는 `--link` 로 첨부하면 미리보기 카드가 붙는다. 링크 도배는 도달이 떨어지므로 CTA가 있는 글에만.
- 캐릭터 대사는 `src/lib/characters.ts`의 greeting 원문 기준. (CAPTIONS.md의 "이름은 말하지 마"는 구버전 — 코드는 "이름은 아직 말하지 마. 먼저 네 눈부터 볼 테니.")
- 나머지 안전 규칙은 CONTENT_DIRECTOR.md 4번 그대로 (단정 금지, 19+/성인/야한 금지, "로그인 후 무료 5회" 표기, 유료 언급 시 "오락 목적의 콘텐츠입니다." 병기).
