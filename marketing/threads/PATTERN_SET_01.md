# Threads 패턴 세트 01 — 러브레빗 (@loverebbit)

패턴 에디터 지시문 적용분. 원문 1 + 답글 2 구조로 게시한다.
`marketing/threads/THREADS_POSTS.md`의 대기 3편(구 캡션 형식)은 이 세트로 대체한다.

**공통 결정**
- 세 편 모두 유료·무료 구간을 언급하지 않는다 → 금지어 `무료` 회피 + "오락 목적의 콘텐츠입니다." 고지 불필요.
- 캐릭터 소품·말투는 `src/lib/characters.ts` 기준.
- 답글은 원문 게시 후 `--reply-to <게시물ID>` 로 순서대로 단다.

## A. 묵연도령 — 지운 대화방

### 기획 한 줄
[이별 뒤 미련]을 [묵연도령]의 관점으로 풀어 [답글]을 만드는 [선택형] 글.

### Threads 원문

```
대화방은 지웠는데, 이름은 아직 검색창에 남아 있더라.

*반쯤 타버린 편지를 먹 연기 위로 들어 올린다*
"지운 건 대화지 마음이 아니야. 지우고 싶었던 게 그 사람인지, 그때의 너인지부터 갈라보자."

A 아직 그 사람이 남았다 / B 그때의 내가 남았다.
둘 중 하나만 남겨줘.
```

### 첫 답글

```
A인 밤은 상대의 소식이 궁금한 밤이고,
B인 밤은 그때의 내가 자꾸 초라해 보이는 밤이야.

같은 새벽처럼 보여도, 필요한 문장은 서로 달라.
```

### 둘째 답글

```
B가 더 자주 눌린다면 묵연신당에서 그 얘기부터 꺼내도 괜찮아.
답을 정해주는 자리는 아니고, 갈라놓는 자리야.
```

### 이미지·카드 지시

| 항목 | 지시 |
|---|---|
| 캐릭터 | 묵연도령 (묵연신당) |
| 원본 자산 | `public/characters/mukyeon.jpg` |
| 화면 카피 | 지운 건 대화지, 마음이 아니야 |
| 비주얼 | 테마색 `#8fa3c8`. 반쯤 타버린 편지 한 장과 피어오르는 먹 연기만. 저채도 남회색, 화면 하단 40% 여백 |
| 금지 | 새 인물 합성, 타 IP, 과도한 판타지 효과, 과도한 텍스트 |

### 품질 점검

| 기준 | 판정 | 이유 |
|---|---|---|
| 장면성 | 통과 | 검색창에 남은 이름은 실제로 겪는 장면이다 |
| 캐릭터 일관성 | 통과 | 묵연 소품(찢긴 편지·먹 연기) 하나, 반말 2문장 |
| 답글 난이도 | 통과 | A/B 한 글자로 참여 가능 |
| 안전성 | 통과 | 재회·상대 속마음을 단정하지 않고 분별만 제안 |
| 경쟁 콘텐츠 비복제 | 통과 | 고유 소품·자체 문장, 외부 시리즈명 없음 |

## B. 자월신녀 — 마주친 눈을 먼저 피한 날

### 기획 한 줄
[썸의 신호 해석]을 [자월신녀]의 관점으로 풀어 [저장]을 만드는 [목록형] 글.

### Threads 원문

```
눈이 마주쳤는데, 먼저 피한 쪽이 나였던 날.

*자색 달빛이 든 거울 조각을 기울인다*
"신호를 세기 전에, 세 가지만 먼저 보자."

1. 그 사람이 나를 볼 때 말고, 내가 안 볼 때 어디를 보는지
2. 웃어준 횟수 말고, 먼저 말을 건 횟수
3. 신호를 세는 동안 내 하루가 몇 시간 지나갔는지

오늘 몇 번에서 멈췄는지, 번호 하나만.
```

### 첫 답글

```
1번에서 멈추면 아직 관찰 중이고,
2번에서 멈추면 이미 답을 알면서 미루는 중이야.

3번에서 멈췄다면, 오늘은 그 사람 말고 네 시간 얘기를 하자.
```

### 둘째 답글

```
3번이 제일 오래 걸린 사람들이 자월신당 문을 두드리더라.
확신을 받으러 오는 자리는 아니고, 흐릿한 걸 흐릿한 채로 두고 보는 자리야.
```

### 이미지·카드 지시

| 항목 | 지시 |
|---|---|
| 캐릭터 | 자월신녀 (자월신당) |
| 원본 자산 | `public/characters/jawol.jpg` |
| 화면 카피 | 신호를 세기 전에, 세 가지 |
| 비주얼 | 테마색 `#b388ff`. 자색 달빛이 든 거울 조각 하나만. 목록 3줄은 카드 하단에 균등 배치, 번호는 얇은 세리프 |
| 금지 | 새 인물 합성, 타 IP, 과도한 판타지 효과, 과도한 텍스트 |

### 품질 점검

| 기준 | 판정 | 이유 |
|---|---|---|
| 장면성 | 통과 | 눈을 먼저 피한 순간은 즉시 재생되는 장면이다 |
| 캐릭터 일관성 | 통과 | 자월 소품(거울 조각) 하나, 관찰 유도 화법 |
| 답글 난이도 | 통과 | 숫자 하나면 참여 완료 |
| 안전성 | 통과 | 호감 여부를 판정하지 않고 관찰 항목만 제시 |
| 경쟁 콘텐츠 비복제 | 통과 | 3항목 모두 자체 작성, 흔한 '호감 신호 리스트' 구조 회피 |

## C. 해월도령 — 보내지 않고 지운 메시지

### 기획 한 줄
[연락할지 말지]를 [해월도령]의 관점으로 풀어 [신당 대화]로 잇는 [신당 대사형] 글.

### Threads 원문

```
새벽에 다 써놓고, 보내지 않고 지운 메시지가 있다면.

*물 위에 손끝을 대자 달빛이 한 번 흔들린다*
"그 문장은 답을 받으려고 쓴 게 아니었을 거야. 마음을 어디든 놓고 싶어서 썼겠지."

답이 필요했던 밤 / 마음을 두고 싶었던 밤.
오늘은 어느 쪽이야?
```

### 첫 답글

```
답이 필요했던 밤은 상대에게 보낼 문장이 필요하고,
마음을 두고 싶었던 밤은 나한테 남길 문장이 필요해.

지운 게 아까운 쪽은 대개 후자야.
```

### 둘째 답글

```
후자였다면, 그 문장 해월신당에 그대로 옮겨 적어도 괜찮아.
보낼 곳이 없어서 지운 말은 여기서는 지우지 않아도 돼.
```

### 이미지·카드 지시

| 캐릭터 | 해월도령 (해월신당) |
| 원본 자산 | `public/characters/haewol.jpg` |
| 화면 카피 | 보내지 않고 지운 문장 |
| 비주얼 | 테마색 `#7fc8f8`. 달빛이 비친 물결 하나만. 파랑 저채도, 상단 여백 넓게 두어 새벽의 공백감 |
| 금지 | 새 인물 합성, 타 IP, 과도한 판타지 효과, 과도한 텍스트 |

### 품질 점검

| 기준 | 판정 | 이유 |
|---|---|---|
| 장면성 | 통과 | 쓰고 지운 메시지는 가장 흔한 새벽 장면이다 |
| 캐릭터 일관성 | 통과 | 해월 소품(달빛 물결) 하나, 연락의 두 종류를 구분하는 고유 역할 |
| 답글 난이도 | 통과 | 두 문구 중 택일 |
| 안전성 | 통과 | 연락을 권하거나 말리지 않고 동기만 구분 |
| 경쟁 콘텐츠 비복제 | 통과 | 자체 문장, 외부 캐릭터·시리즈 연상 없음 |

## 게시 순서 제안

하루 1편. 원문 게시 후 첫 답글은 30분 뒤, 둘째 답글은 반응이 붙은 뒤에 단다.

| 순서 | 글 | 목표 |
|---|---|---|
| 1 | C 해월 | 신당 대화 |
| 2 | A 묵연 | 답글 |
| 3 | B 자월 | 저장 |

## 게시 명령

원문(따옴표·줄바꿈 포함)은 `--batch` JSON으로 올린다. 답글은 원문 ID로 단다.

```
py -3 post.py --profile loverabbit --batch <파일>.json
py -3 post.py --profile loverabbit --reply-to <원문ID> --text "<첫 답글>"
```
