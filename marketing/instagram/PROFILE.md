# 인스타그램 프로필 — 러브레빗

프로필 사진·이름·소개 한 세트. 이름과 소개는 그대로 복사해서 붙여 넣으면 됩니다.

---

## 1. 프로필 사진

`marketing/instagram/profile/` 에 두 가지 안이 있습니다. 둘 다 1080×1080, 원형 크롭 기준으로
토끼·장식이 모두 안전 영역 안에 들어옵니다.

| 파일 | 결 | 언제 쓰나 |
|---|---|---|
| `loverabbit-profile-dark.jpg` | 앱과 같은 자정 보라 + 로즈/바이올렛 글로우 | 앱·광고 소재와 톤을 맞추고 싶을 때 (기본 추천) |
| `loverabbit-profile-rose.jpg` | 로즈 핑크 단색 배경 | 피드 썸네일에서 눈에 띄는 쪽을 원할 때 |

`preview-circle-*.png` 는 인스타가 실제로 잘라 보여주는 원형 미리보기입니다. 업로드용은 `.jpg` 쪽입니다.

다시 만들려면:

```bash
node marketing/instagram/compose-profile.mjs
```

`public/logo.png` 에서 토끼만 오려내 배경을 새로 깔기 때문에, 로고를 바꾸면 프로필 사진도 같이 갱신됩니다.
이미지 생성 API를 쓰지 않아 크레딧이 들지 않습니다.

## 2. 사용자 이름 (핸들)

이미 제작된 광고·그리드 소재에 `@loverabbit` 이 찍혀 있으므로 **1순위는 `loverabbit`** 입니다.
선점돼 있으면 아래 순서로 내려가되, 소재의 핸들 표기도 함께 바꿔야 합니다
(`marketing/ads/compose-*.mjs`, `marketing/ads/compose-instagram-grid.mjs` 안의 `@loverabbit`).

1. `loverabbit` — 소재와 일치, 가장 짧음
2. `loverabbit.ai` — 서비스 성격(AI 사주)이 바로 읽힘
3. `loverabbit_kr` — 국내 계정 표시
4. `loverabbit.official` — 위가 전부 막혔을 때

## 6. 프로필 설정

- **카테고리**: 엔터테인먼트 웹사이트 (또는 앱 페이지)
- **계정 유형**: 크리에이터 대신 **비즈니스** — 인사이트·광고 연동에 필요
- **연락처 옵션**: 이메일만 노출, 주소·전화는 숨김
- **성인 표기 주의**: 프로필에 `19+`, `성인`, `야한` 같은 표현은 넣지 마세요.
  광고 심사와 추천 노출에서 계정 전체가 제한될 수 있습니다. 앱 안에서만 표기하고,
  인스타에서는 "속궁합·연애운" 정도의 표현으로 유지하는 편이 안전합니다.
