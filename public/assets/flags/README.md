# 오방기 (2026-09-02)

다섯 장. 400x400 webp, 장당 7~9KB, 합쳐 48KB.

```

hwa.webp    적(赤) · 화 · 남 · 여름
to.webp     황(黃) · 토 · 중앙
geum.webp   백(白) · 금 · 서 · 가을
su.webp     흑(黑) · 수 · 북 · 겨울
```

오방기(五方旗)는 무속·의례에서 다섯 방향을 부르는 깃발이고 오행과 그대로
맞물린다. 색은 전통 오방색을 따른다 — **화면의 오행 막대 색과 다르다.**
막대는 현대적 해석(목=초록)을 쓰고 깃발은 전통(목=청)을 쓴다. 청(靑)은
초록과 파랑을 아우르는 옛 범주라 둘이 모순은 아니다.

## 같은 깃발이어야 한다

처음에 다섯을 각각 만들었더니 깃대 각도·장식·크기가 제각각이었다. 나란히
세우면 줄이 안 맞아 뽑기가 안 된다.

지금은 **청색 한 장을 만들고 그것을 image_references 로 넣어 색만 바꿨다.**
새로 만들 때도 그렇게 해라 — 프롬프트에 "keep the pole, position, scale,
lighting identical, only the cloth color changes" 를 넣는다.

## 배경 제거

`remove_background` (media_type: image) 를 쓴다. **흰색 키잉을 쓰지 마라** —
백색 깃발은 천도 희어서 천까지 뚫린다. 실제로 그렇게 해봤고 구멍이 났다.

배경제거기는 진짜 알파를 돌려준다(영상과 달리 이쪽은 png 라 알파가 담긴다).
마스크를 다시 만들 필요 없이 그대로 쓰면 된다.
