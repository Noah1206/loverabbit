# 홈 배너 (2026-09-01)

login-banner.webp — 비로그인에게 보이는 로그인 유도 배너. 1200x420, 14KB.
member-banner.webp — 로그인한 사람에게 보이는 배너. 1200x420, 11KB.
같은 토끼가 손을 흔드는 대신 두루마리를 펼쳐 보인다 — 이미 들어온 사람에게
필요한 것은 인사가 아니라 다음 걸음이다.

둘 다 Higgsfield nano_banana_pro, 3D 렌더, 2크레딧. member 쪽은 login 쪽을
레퍼런스로 넣어 같은 얼굴·같은 옷·같은 렌더링을 유지했다.

## 글자가 없다

그림에는 문구가 없다. 배경으로 깔고 텍스트는 CSS 로 왼쪽에 얹는다 —
카피를 바꿔도 이미지를 다시 만들 필요가 없고, 번역도 마크업에서 끝난다.

## 왼쪽 3분의 2는 비어 있다

토끼가 오른쪽에 있고 왼쪽은 단색이라 글이 얼굴을 덮지 않는다.
**새 그림으로 갈아끼울 때 이 약속을 지켜야 한다** — 캐릭터가 가운데로 오면
문구가 그 위에 앉는다. 배경색도 CSS 의 background-color 와 맞춰야 이미지가
뜨기 전에 색이 튀지 않는다 (지금은 #d9bdde).

## 비율

1200:420 (가로의 35%). CSS 의 aspect-ratio 와 같아야 한다 — 다르면 잘리거나
늘어난다.
