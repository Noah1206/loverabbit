감정 결을 새로 추가할 때
========================

1) 그림 3장을 넣는다 (같은 결, 밝기 세 단계)

   public/assets/love-rabbit/scenes/scene_<영문키>_dark.png
   public/assets/love-rabbit/scenes/scene_<영문키>_mid.png
   public/assets/love-rabbit/scenes/scene_<영문키>_bright.png

   1024x1024. 그림체는 다른 30장과 같아야 한다 -
   Moonlit Rabbit Oracle: 얇은 진회색 선화, 깨끗한 셀 채색,
   달빛 남청 / 자두 보라 / 크림 / 금색, 절제된 푸른 림라이트,
   밝은 포인트 하나.

2) 웹용으로 줄인다

   node scripts/optimize-love-rabbit-assets.mjs

3) src/data/love-rabbit-assets.json 의 assets 배열에 3줄 추가

   {
     "assetId": "scene_<영문키>_mid",
     "kind": "scene",
     "emotionTag": "<한글 태그>",
     "brightness": "mid",
     "path": "scenes/scene_<영문키>_mid.png"
   }

   dark / bright 도 같은 모양으로. index, rawUrl, jobId 같은 칸은 없어도 된다.

4) 확인

   npx tsx scripts/verify-love-rabbit-assets.mts
   npm test
