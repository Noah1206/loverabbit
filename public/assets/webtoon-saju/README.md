# 웹툰 사주 컷 (2026-09-01)

운세 셋 × (표지 1 + 패널 4) = 15장. Higgsfield nano_banana_pro, 장당 2크레딧.
로고 토끼(public/logo.png)를 레퍼런스로 넣어 15장의 토끼가 같은 얼굴이 되게 했다.

## 모든 컷이 지키는 약속

이 약속이 깨지면 말풍선이 화자를 덮는다. 새 컷을 만들 때도 같은 규약으로 뽑아야 한다.

  · **상단 34% 는 비어 있다** — 말풍선이 앉는 자리. 하늘이든 벽이든 잔잔한 그라데이션만.
  · **토끼는 아래 왼쪽 또는 아래 오른쪽** — bubbleAt() 의 앵커와 짝이 맞아야 한다.
  · **사람 얼굴은 보이지 않는다** — 뒷모습·실루엣·그림자. 실존 인물을 그리지 않는다는
    리딩 이미지 원칙과 같다.
  · **글자가 없다** — 문장은 전부 React 오버레이가 그린다. 이미지에 구우면 카피를
    고칠 때마다 그림을 다시 만들어야 하고, 명식 기반 문장을 덮어쓸 수 없다.

## 화풍

맑은 진회색 선화, 셀 채색, 넉넉한 여백.
달빛 남청·인디고 / 크림·아이보리 / 자두보라 그림자 / 절제된 금색 포인트 하나.
