# 웹툰 사주 컷 (2026-09-01)

운세 셋 × 8컷 = 24장. Higgsfield nano_banana_pro, 3:4, 장당 2크레딧.
표지는 각 운세의 01번 컷을 그대로 쓴다 — 따로 뽑으면 톤이 어긋난다.

## 사람이 없다

처음에는 사용자를 뒷모습으로 그렸다. 그러면 성별·나이·체형을 매번 가정하게 되고,
어느 쪽으로 그려도 절반은 "내가 아니다". 사람을 아예 빼니 그 문제가 사라졌고,
누구에게나 자기 이야기가 된다. 사용자는 이름으로만 불린다.

## 8컷 구조

    01 맞이함 (화자)   02 전환 (배경)   03 짚어줌 (화자)   ← 무료
    04 소품 (정물)     05 걱정함 (화자)  06 경과 (배경)
    07 풀어줌 (화자)   08 배웅함 (화자)                    ← 유료

말하는 얼굴만 이어지면 대화록이지 웹툰이 아니다. 그래서 화자 컷 사이에
배경·소품 컷을 끼운다. 연결 컷은 화자가 없으므로 말풍선 대신 캡션 한 줄이 붙는다.

## 컷마다 다르게

샷    상반신 / 얼굴 클로즈업 / 앞발 디테일 / 전신
표정  밝음 · 진지 · 놀람 · 걱정 · 사색 · 윙크 · 따뜻
각도  정면 / 3-4 좌 / 3-4 우 / 내려봄

얼굴은 고정이다. 클로즈업 한 장을 캐릭터 시트로 만들어 레퍼런스로 넘긴다
(scratchpad/webtoon/charsheet.png). 로고(네 발 토끼)를 레퍼런스로 쓰면 매번
다른 얼굴이 나온다 — 필요한 것은 의인화된 얼굴이기 때문이다.

## 화자 컷의 계약 — 위쪽 45% 가 비어 있다

말풍선이 앉을 자리다. 코드의 bubbleAt() 이 이 약속 위에서 좌표를 정하므로,
새 컷도 반드시 같은 규약으로 뽑아야 한다.

**비율을 숫자로 지시하면 안 된다.** "상단 45%를 비워라"라고 썼더니 모델이 그
경계를 **선으로 그었다** — 24장 중 15장에 가로 이음선이 생겼다. 대신 사진으로
말한다:

> 얕은 심도 렌즈로 찍은 사진 한 장. 피사체가 프레임 아래에 앉고 머리 위로 흐린
> 방이 넓게 펼쳐진다. 배경은 거리에 따라 점점 흐려지는 하나의 대기층이다.
> **한 방을 찍은 한 장의 사진이지 만화 페이지가 아니다.**

그을 숫자가 없으니 선도 없다.

## 4:5 가 아니라 3:4

4:5 로는 "토끼를 크게"와 "위를 비워라"가 충돌해 12장 중 8장이 여백 0% 였다.
3:4 는 세로가 길어 둘 다 된다.

## 글자가 없다

문장·캡션·효과음 전부 오버레이가 그린다. 이미지에 구우면 카피를 고칠 때마다
그림을 다시 만들어야 하고, 명식 기반 문장을 덮어쓸 수 없다.

## 화풍

맑은 진회색 선화, 셀 채색, 넉넉한 여백.
달빛 남청·인디고 / 크림·아이보리 / 자두보라 그림자 / 절제된 금색 포인트.

## 검사

새 컷을 넣으면 scratchpad/webtoon 의 두 검사를 돌린다.
  seamcheck.cjs   이음선 (전 구간을 본다 — 상단만 보면 53% 의 선을 놓친다)
  headroom.cjs    상단 여백 (화자 컷만)

## 청월당 레퍼런스

시각 문법만 봤다 — 말풍선이 화자 위에 뜨고 꼬리가 화자를 가리키는 배치, 컷 리듬,
여백, 연결 컷의 역할. 운영자가 사용 권한을 확인해 주었다.
텍스트·로고·캐릭터·구도는 복제하지 않았다.
